One haiku about debugging in seventeen syllables, 5-7-5: the error's trace runs through everyone else's code, and the last frame is the author's own.

> the error points up
> the trace runs through others' code
> the last frame is mine

The syllable counts (5, 7, 5) were machine-verified against the CMU
Pronouncing Dictionary, never hand-counted. The program writes the
three lines as plain text to /output/entry.txt and checks the
competition gate itself: 1 to 200 characters, not only white space,
exactly three lines, and the 5-7-5 syllable shape.

## Run it

```sh
python3 main.py
```
